# Card Vault (Electron)

Coleção de Magic: The Gathering com preços Cardmarket (Trend + From), histórico, variações e gráficos.

## Correr
1. Instala o Node.js (https://nodejs.org, versão LTS).
2. No Terminal, dentro desta pasta:
   npm install
   npm start

## Criar a app (.dmg)
   npm run dist
O instalador aparece em dist/. Como não está assinada, na primeira abertura: clique direito > Abrir.

## Dados
Ficam em ~/Library/Application Support/card-vault/ (vault.json). Usa Definições > Backup.
